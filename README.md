Load Balancer
Distributes traffic across multiple application servers.
Prevents a single server from becoming overloaded.
API Gateway
Single entry point for all client requests.
Handles authentication, rate limiting, and routing.
Application Servers
Stateless services that process requests.
Easy to scale horizontally.
Message Queue (Kafka/RabbitMQ)
Handles asynchronous tasks.
Decouples services and improves reliability.
Database
MongoDB (NoSQL) for flexible schema and high scalability.
Redis can be added for caching if needed.
